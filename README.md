# Rajat Jain — Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Free publishing options

### GitHub Pages
1. Create a public GitHub repository named `yourusername.github.io`.
2. Upload the contents of this folder (keep `assets/` in place).
3. In repository Settings → Pages, select deploy from the `main` branch and `/ (root)`.
4. Your site will be published at `https://yourusername.github.io`.

### Netlify
1. Sign in at https://www.netlify.com/.
2. Choose Add new site → Deploy manually.
3. Drag the whole portfolio folder into the deploy area.
4. Netlify will provide a free `*.netlify.app` address.
