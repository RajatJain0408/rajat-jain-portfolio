Independent project · AI / Python

RAG Research Chatbot

A local document question-answering project built to understand the complete retrieval-to-generation flow.

Problem

When asking questions about long documents, searching manually takes time. A language model can also produce answers without enough supporting context.

What I built

Created a Python pipeline to read documents, split text into chunks, generate embeddings, store vectors in FAISS, retrieve relevant passages and pass that context to a local Ollama model.

What I tested

The project generated 765 chunks with all-MiniLM-L6-v2 and used llama3.2:3b. I ran 10 evaluation questions and recorded 58.33% average keyword coverage. That gave me a baseline and highlighted the need to improve retrieval and answer relevance.

Stack

Python, sentence-transformers, embeddings, FAISS, Ollama, Llama 3.2.
